# PRIME Detailing Landing Page

Bilingual NL/EN static landing page starter for PRIME Detailing, Zwolle.

## Run locally
No build step is required.

Option 1: open `index.html` directly.

Option 2 (recommended):
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.

## Deploy
This project is intentionally static and can be deployed to Netlify, GitHub Pages or any normal web host.

## Files Codex should read first
1. `AGENTS.md`
2. `CODEX_TASK.md`
3. `BRAND_GUIDE.md`
4. `CONTENT.md`
5. `QA_CHECKLIST.md`
